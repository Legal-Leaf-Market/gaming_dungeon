Drop the Godot web export of Drowned Signal directly in this folder.

Export from the drowned_signal_35_web (or newer) project version - it has the
web audio optimizations. In Godot 4.3+:

  Project > Export > Web
    - Thread Support: OFF   (recommended: works everywhere, incl. iOS Safari,
      and needs no COOP/COEP headers - see the trap note at the top of
      public/js/arcade-games.js before you even think about threads ON)
    - Progressive Web App: Off
  Export Project  ->  save as index.html into THIS folder
    - UNTICK "Export With Debug" in the save dialog (critical for speed)

Expected files after export:
  index.html, index.js, index.wasm, index.pck,
  index.audio.worklet.js (+ any other index.* files)

Godot's generated index.html is used AS-IS; it is loaded in an iframe by
arcade-play.js, so inline scripts are fine here.

Then, in public/js/arcade-games.js, set this game's entry:
  embed: "/arcade/drowned-signal/"
and correct `weight` to the real download size. Leave `listed: false` until
Brayton signs off (the permission note in that file is about his games).
The cabinet is playable at /arcade?all=1 or /arcade?g=drowned-signal
before it is listed - that is how to QA it.

QA: open the cabinet -> audio starts on first input -> Esc pauses ->
refresh resumes with saved progress (IndexedDB, per-origin, stays in the
player's browser - nothing server-side is needed).
