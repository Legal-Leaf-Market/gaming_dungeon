# ============================================================
# PRE-LAUNCH. THE WHOLE SITE IS CLOSED TO CRAWLERS ON PURPOSE.
# ------------------------------------------------------------
# Two facts make this the right posture today, and both stop being
# true on the same day:
#
#   1. NOTHING IS PUBLISHED. 54 merchants are registered and none has
#      cleared the capture gate, so every room says "nothing is
#      stocked yet". Letting Google index that costs us the first
#      impression on every one of these URLs to sell an empty shop.
#
#   2. THIS IS A THROWAWAY ADDRESS. gaming-dungeon.vercel.app is a
#      deploy URL, not the domain. If it gets indexed and a real
#      domain lands later, the two compete: duplicate content, split
#      signal, and a canonical mess that is far more work to unpick
#      than it ever was to prevent.
#
# Blocking now costs nothing, because there is nothing to index.
#
# ------------------------------------------------------------
# HOW TO OPEN IT, WHICH IS THE PART THAT GETS FORGOTTEN
# ------------------------------------------------------------
# When a real domain is live AND at least one merchant is published:
#
#   1. Replace everything below with the LAUNCH block at the bottom.
#   2. Set SITE_URL to the real domain and run `npm run sitemap`.
#   3. Check /sitemap.xml lists what you expect and nothing noindex.
#
# A `Disallow: /` nobody remembers to remove is a site that quietly
# never gets traffic, and the symptom — "our SEO isn't working" —
# points nowhere near this file. It is in CLAUDE.md's launch
# checklist for that reason.
# ============================================================

Disallow: /
